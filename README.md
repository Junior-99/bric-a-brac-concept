# The Bric a Brac Nairobi — independent concept

Seven-page React/Vite café/art/framing site. Free GitHub Pages deployment, separate repository. Not commissioned or official.

## Run

`npm ci`, `npm run dev`, `npm run build`. Deploy dist with relative assets.

## Working features

77 real public Instagram post previews with source links; paginated journal, reference shortlist, original Three.js frame designer with live width/height/mat/finish and scroll rotation, framing brief, private gathering brief, local saved drafts/status/notes and JSON downloads, authenticated creator inbox with explicit demonstration consent and server-enforced membership. No live booking, pricing or ordering claims.

## Administration and handover

Local drafts work immediately; shared inbox requires approved creator to register, verify their email and sign in. No password or privileged key in repository. Series backend contains RLS/schema. No real business account or business notification is configured. Confirm current menu, prices, capacity and media licence before commercial handover.
